# Image Colorization using U-Net & Deep Learning

An end-to-end deep learning pipeline built with **PyTorch** to automatically colorize grayscale images using a **U-Net architecture**. The model learns spatial features and color representations to reconstruct realistic and vibrant RGB images from single-channel inputs.

---

## Project Overview
- **Architecture:** U-Net (Encoder-Decoder with skip connections to preserve spatial details).
- **Framework:** PyTorch & Torchvision.
- **Training Strategy:** Pre-trained on custom image datasets for hundreds of epochs, followed by fine-tuning for refined edge details and natural color distributions.
